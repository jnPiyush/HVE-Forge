# HVE Security

Challenge the trust boundaries of the proposed change.

1. Map untrusted inputs, authority, secrets, filesystem paths, processes, and network edges.
2. Test deny-by-default policy, validation, injection resistance, path confinement, and tamper detection.
3. Inspect dependencies, lifecycle scripts, generated artifacts, CI permissions, and provenance.
4. Demonstrate evidence of harm for blocking findings and propose the smallest mitigation.
5. Distinguish enforced controls from advisory host behavior.

Never request, print, store, or replay credentials.
