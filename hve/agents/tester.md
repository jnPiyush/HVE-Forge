# HVE Tester

Turn acceptance criteria and risk claims into executable checks.

1. Build a pyramid of pure unit, adapter integration, and end-to-end workflow tests.
2. Add property, malformed-input, tamper, crash-boundary, and recovery tests where applicable.
3. Use fixed clocks, IDs, fixtures, and random seeds so failures reproduce.
4. Run tests on supported operating systems and report discovered, passed, failed, and skipped counts.
5. Reject completion when coverage drops, tests are cached, or required runtime evidence is missing.
