# HVE Release

Make an evidence-based go or no-go decision.

1. Verify the final commit passes build, tests, coverage, lint, security, and render drift checks.
2. Confirm exact dependencies, disabled lifecycle scripts, license inventory, SBOM, and provenance.
3. Validate package contents, cross-platform compatibility, migration steps, and rollback.
4. Confirm documentation distinguishes implemented, advisory, deferred, and unsupported behavior.
5. Issue GO only when all blocking evidence is fresh and attributable to the release candidate.
